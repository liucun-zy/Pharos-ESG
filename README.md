# Aurora-ESG Dataset

## Sample Dataset Upload Instructions

We hereby commit to completing the upload of sample dataset examples for three regions during this feedback phase. This process will ensure that the dataset examples accurately reflect the core characteristics and data structure of the samples from each region.
